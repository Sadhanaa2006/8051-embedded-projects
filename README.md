💡 **LED Blinking System**

🔗 https://github.com/Sadhanaa2006/led-blink-project 

🔢 **7-Segment Display System**

Displays digits from 0 to 9 using lookup table (array method) in Embedded C.

🔗 https://github.com/Sadhanaa2006/7-segment-display-project
<br>

🚦 **Traffic Light Control System**

Simulates real-world traffic signals using LEDs with timed delays.

🔗 https://github.com/Sadhanaa2006/traffic-light-control-system


🚪 **Automatic Door Control System**  

Sensor-based system controlling motor direction for automatic door open/close automation.

A multi-sensor automation system using IR, LM35, and LDR with 8051 to control appliances and lighting based on environmental conditions.
